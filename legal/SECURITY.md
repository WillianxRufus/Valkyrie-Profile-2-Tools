# Security policy

Report vulnerabilities through GitHub's private vulnerability reporting or a
private security advisory once the repository is published. Do not include a
game image, extracted resource, save state, secret, or personal data in a
report; use a minimal synthetic reproduction whenever possible.

Only the latest tagged release and the current default branch are supported.
Translation mistakes, unsupported game revisions, and ordinary build failures
belong in the public issue tracker unless their disclosure would create a
security risk.
